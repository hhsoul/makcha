# 막차알림 🚇

현재 위치에서 집까지 막차를 계산하고, 술자리에서 출발 시간을 알려주는 웹앱(PWA)입니다.

## 실행 방법 (PC)

1. 이 폴더에서 PowerShell을 열고 실행:
   ```
   powershell -ExecutionPolicy Bypass -File serve.ps1
   ```
2. 브라우저에서 http://localhost:8787 열기
3. ⚙️ 설정 → 집 주소 검색 → 결과 선택 → 저장

## 기능

| 기능 | 동작 방식 |
|---|---|
| 막차 시간 계산 | 현재 위치~집 거리로 대중교통 시간과 막차를 **추정**. 설정에 막차 시각을 직접 넣으면 그 값을 우선 사용 |
| 30분 전 알림 | 🍻 술자리 모드를 켜면 출발 30분 전·10분 전·출발 시각에 알림 + 진동 + 소리 + 팝업 (몇 분 전인지 설정 가능) |
| 택시비 예상 | 서울 중형택시 요금 + 심야할증(22~04시) 기준 범위 표시 |
| 대체 경로 | 막차 / 중간까지+택시 / 심야버스 / 택시 / 첫차 중 가능한 것과 가장 싼 것 추천 |
| 위치 공유 | 카카오맵 위치 링크 + 귀가 계획을 카톡·문자 등으로 공유 |

## 꼭 알아두세요

- **시간과 요금은 추정치예요.** 실제 시간표 API를 쓰지 않아서, 정확한 막차는 "카카오맵 실제 경로" 버튼으로 확인하고 설정에 직접 넣는 게 가장 정확해요.
- **알림은 앱 화면이 켜져 있을 때만 확실히 울려요.** 웹앱은 꺼진 상태에서 예약 알림을 보낼 수 없어서, 술자리 모드에서는 화면 꺼짐 방지를 켜요.
- **위치 공유는 한 번 보내는 방식이에요.** 친구가 실시간으로 계속 보려면 서버가 필요해요.
- 집 주소, 친구 번호 같은 설정은 이 기기 브라우저에만 저장돼요.

## 폰에서 쓰려면

위치·알림 기능은 보안 연결(https)에서만 작동해서, PC의 localhost 주소를 폰에서 그냥 열면 안 돼요.
GitHub Pages나 Netlify 같은 무료 호스팅에 이 폴더를 올리면 https 주소가 생기고, 폰 크롬에서 "홈 화면에 추가"로 앱처럼 쓸 수 있어요.
